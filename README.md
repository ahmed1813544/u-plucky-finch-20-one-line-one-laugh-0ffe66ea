## The entry

`main.py` (stdlib only, deterministic, no network) writes one funny line of
text to `/output/entry.txt`:

> My smart fridge just locked the ice cream drawer, emailed me a diet plan, and changed its own password.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.
